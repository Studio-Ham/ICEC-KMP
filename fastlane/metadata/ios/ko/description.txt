ICEC (Mosaic Editor Creator)는 기기 안에서 사진 속 얼굴을 찾아 가리는 사진 편집 앱입니다.

주요 기능
- 기기 내 얼굴 검출: 기기에서 사진을 고르면 기기 안에서 얼굴을 찾습니다.
- 얼굴 선택 가리기: 사용자가 고른 얼굴만 사각 픽셀 모자이크로 가립니다.
- 확대와 이동: 사진을 확대하거나 이동해 얼굴을 정확히 확인하고 고릅니다.
- 원본 보존과 원본 해상도 저장: 원본 사진은 바꾸지 않습니다. 선택한 얼굴만 가린 새 사진을 원본 해상도로 저장합니다.
- 메타데이터 제외: 저장한 새 사진에는 GPS를 포함한 메타데이터가 없습니다.

개인정보 보호
- 계정, 로그인, 광고, 결제, 개발자 서버, 개발자 분석 도구가 없습니다.
- 사진과 얼굴 분석 데이터는 개발자나 외부 서버로 보내지 않습니다.
- 얼굴 검출에는 Google ML Kit를 기기 안에서 실행합니다.
- Google ML Kit는 SDK 사용 통계와 성능 지표를 Google로 보낼 수 있습니다. 사진과 얼굴 데이터는 보내지 않습니다.

지원 언어
- 한국어, 영어
